## 我的理念

在 2022 年初，我创立了 **OpensRun**：  
- **Open**：保持开放与探索的心态  
- **Run**：在不确定中持续前行  

我曾尝试创立教育品牌，也在那段经历中意识到：  
- 教育不该只围绕“分数”运转  
- 技术也不该成为制造焦虑的工具  

随着 AI 的快速发展，“唯分数论”的意义进一步被削弱。  
最终我选择**回到产品与工程本身**，把精力投入到这样几件事上：

> 用技术做真正有价值、可长期陪伴用户的工具，  
> 让 AI 和软件 **减少负担、提升效率，而不是放大焦虑**。
