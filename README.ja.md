## 技術スタックとスキル

### プラットフォームと言語

- **クライアント**
  - macOS / iOS ネイティブ開発  
  - Swift に精通し、Objective‑C / C++ も経験豊富  
  - Xib / Storyboard / AppKit / SwiftUI で複雑な UI を構築可能  

- **フルスタック**
  - Web フロントエンド：React などのモダンフレームワークに精通  
  - バックエンド：Python などを用いた API / 業務システムの設計・実装  
  - **フロント + バックエンド + クライアント** を一人で完結できる体制  

### AI エンジニアリング

- **ローカルモデルとクラウド LLM** を macOS アプリ（例：Yulan）に統合  
- マルチソース検索、RAG、コンテキスト管理、ツール呼び出しなどの AI アプリ設計に精通  
- レイテンシ・リソース消費・プライバシーを考慮し、「性能」と「実運用可能性」のバランスを取る  
- AI と **デスクトップ OS レベルの機能**（グローバル検索、ランチャー、システム連携など）の統合経験  

### リバースエンジニアリング・セキュリティ・システム

- URLSession の並行処理、NetworkExtension などのネットワークフレームワークに精通  
- CommonCrypto / Security / EndpointSecurity などのセキュリティフレームワークに習熟  
- USB / Bluetooth を用いたソフトウェア・ハードウェア連携の経験  
- **リバースエンジニアリング / エンドポイントセキュリティツール** の実務経験。システムコール、権限モデル、サンドボックス機構を理解。  
- 「防御側」の視点からエンドポイント防御とアプリケーションセキュリティを設計可能。  

### Web3.0 と未来のソフトウェア

- Web3.0（分散化、デジタル資産、データ主権など）の動向を継続的に追跡。  
- 概念や投機ではなく、「実際のプロダクトでどう活用するか」にフォーカス。  
- プロダクト設計では、**「今すぐ使えること」と「将来の拡張性」** の両方を重視。  

### エンジニアリングプラクティス

- アーキテクチャ：**MVVM** に精通し、Combine などの非同期フレームワークにも対応。  
- ツール：**Xcode / Instruments / lldb** を用いた性能・メモリ解析が可能。  
- コラボレーション：Git を用いたチーム開発の経験。  
- リリース：署名・公証・サンドボックス・ストア申請など、リリースフロー全体を理解。
