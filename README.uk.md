## Про мене

-  Понад 10 років досвіду розробки під macOS / iOS – від внутрішнього інженера до незалежного розробника та засновника。  
-  У 2022 році я заснував **OpensRun** і працюю над продуктами **Yulan** (розумний асистент для macOS) та **YanciPai** (інструмент для вивчення англійської мови)。  
-  Умію **перетворювати можливості ШІ на реальні продукти** – від дизайну та вибору технологій до розробки й релізу。  
-  Маю досвід у **зворотній розробці, безпеці кінцевих пристроїв та системних механізмах захисту**。  
-  Цікавлюся **Web3.0, децентралізацією та суверенітетом даних**, із практичним поглядом на застосування。  
-  Працюю як **full‑stack** інженер: frontend, backend і клієнтські застосунки。

## Моя філософія

На початку 2022 року я створив **OpensRun**:  
- **Open** – залишатися відкритим і допитливим  
- **Run** – рухатися вперед навіть в умовах невизначеності  

Досвід у сфері освіти показав мені, що:  
- Освіта не повинна обмежуватися лише оцінками。  
- Технології не повинні бути інструментом для посилення тривоги。  

Із швидким розвитком ШІ «культ оцінок» стає ще менш актуальним。  
Тому я вирішив **повернутися до продукту та інженерії** й зосередитися на:

> Створенні інструментів, які приносять реальну користь і можуть довго супроводжувати користувачів,  
> Використанні ШІ та ПЗ для **зменшення навантаження й підвищення ефективності, а не для посилення тривоги**。

## Технологічний стек та навички

### Платформи та мови

- **Клієнт**
  - Нативна розробка для macOS / iOS  
  - Експерт у Swift, досвід з Objective‑C / C++  
  - Вміє створювати складні інтерфейси з Xib / Storyboard / AppKit / SwiftUI  

- **Full‑stack**
  - Веб‑фронтенд: знайомий з сучасними фреймворками, такими як React  
  - Бекенд: досвід з Python та пов'язаними стеками, здатний проектувати та реалізовувати API‑сервіси та бізнес‑системи  
  - Може самостійно реалізувати повний продукт **frontend + backend + client**  

### Інженерія ШІ

- Інтеграція **локальних моделей та віддалених LLM** у додатки macOS (наприклад, Yulan)  
- Знання багатоджерельного пошуку, RAG‑пошуку, управління контекстом, викликів інструментів та загальних форм застосування ШІ  
- Увага до затримки, використання ресурсів та конфіденційності, балансування між "ефективністю" та "можливістю впровадження"  
- Практичний досвід поєднання ШІ з **можливостями рівня системи робочого столу** (глобальний пошук, швидкий запуск, інтеграція системи тощо)  

### Зворотна розробка, безпека та система

- Досвід роботи з паралельним програмуванням URLSession, NetworkExtension та іншими мережевими фреймворками  
- Знання CommonCrypto / Security / EndpointSecurity та інших фреймворків безпеки  
- Досвід створення рішень, які взаємодіють з апаратним забезпеченням через USB / Bluetooth  
- Практичний досвід роботи з інструментами **зворотної розробки / безпеки кінцевих пристроїв**, розуміння системних викликів, моделей дозволів та механізмів sandbox  
- Здатність мислити про захист кінцевих пристроїв та безпеку додатків з точки зору "захисника"  

### Web3.0 та майбутні форми програмного забезпечення

- Постійне відстеження Web3.0: децентралізація, цифрові активи, суверенітет даних тощо  
- Більше уваги до "як правильно використовувати ці ідеї в продуктах", а не до хайпу та спекуляцій  
- При проектуванні продуктів завжди балансується між **"практичним зараз" + "розширюваним у майбутньому"**  

### Інженерні практики

- Архітектура: експерт у **MVVM**, знайомий з Combine та іншими асинхронними фреймворками  
- Інструменти: компетентний у **Xcode / Instruments / lldb** для аналізу продуктивності та пам'яті  
- Співпраця: досвід роботи з Git для контролю версій та командного співробітництва  
- Випуск: знання підпису додатків, нотарізації, sandbox та процесу випуску в App Store
